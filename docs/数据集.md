# 数据集准备与独立发布

本仓库只保存源码与说明。数据集下载入口集中在 [英文 README](../README.md#dataset-downloads) 与[中文 README](../README.zh-CN.md#dataset-downloads)，实际文件上传后同步替换两处待上传位置。

## 推荐：发布完整处理目录

```text
data/processed/
├── metadata.json
├── index.npy
└── raw/
    ├── Gnt1.0Test/
    ├── Gnt1.0TrainPart1/
    ├── ...
    ├── emnist-train.idx
    └── emnist-test.idx
```

`metadata.json` 保存类别顺序、划分、书写者、原始文件相对路径与索引 SHA-256；`index.npy` 只记录样本位置，并不包含图像。**必须包含元信息引用的全部 `raw/` 文件**，同时保留目录结构和原文件名。训练时通过内存映射读取，无需导出数百万张 PNG。

**只上传完整 `processed/` 就足够重新训练和完整评估。** 当前元信息引用 1,022 个原始文件，均已检查存在，索引 SHA-256 也已核对。`data/CASIA-HWDB/` 与 `data/EMNIST/` 中的 ZIP/GZ 是原始压缩备份，`processed/raw/` 是实际运行所需的提取文件；训练不会同时读取两个目录，因此保留压缩备份不会导致样本被重复加入训练。不要删除 `processed/raw/`。

单图识别只需要源码、依赖与发布模型，不需要上传或下载 `processed/`。源数据包仅在需要重新构建划分/索引时使用，可以保留为本地备份。

类别顺序是 `0–9`、`A–Z`、`a–z`，随后为排序后的 7,185 个汉字，共 7,247 类。

| 划分 | 有效图像 | 覆盖类别 |
|---|---:|---:|
| 训练 | 3,353,310 | 7,247 |
| 验证 | 374,648 | 7,247 |
| 测试 | 870,895 | 7,247 |

当前准备参数为 seed 42、验证比例 0.1，索引 SHA-256 为：

```text
ab95cdd227094c2e2b221ff958adce0d42b6b30a76089473316cbf4ec6b380b3
```

此校验值仅对应当前 `index.npy`，不能替代整个发布包的校验。改变划分或重建索引后，应重新记录数据版本与校验值。

下载完整处理包后，在项目根目录运行：

```bash
.venv/bin/python check_environment.py --device auto
```

Windows 改用 `.\.venv-win\Scripts\python.exe`，NVIDIA 训练可指定 `--device cuda`。该检查会核对数据路径和设备，并运行小规模设备运算；发布包本身仍应按提供的 SHA-256 校验。

## 从原始数据重新准备

CASIA 来源：[官方下载页面](https://nlpr.ia.ac.cn/databases/handwriting/Download.html)，本项目此前使用的[第三方镜像](https://huggingface.co/datasets/OrkaZeta/HWDB1/tree/main)。EMNIST 来源：[NIST 官方页面](https://www.nist.gov/itl/products-and-services/emnist-dataset)，采用 ByClass，而不是合并大小写标签的 Letters 划分。

`data/CASIA-HWDB/` 需要以下文件：

```text
chinese_characters.txt
Gnt1.0Test.zip
Gnt1.0TrainPart1.zip
Gnt1.0TrainPart2.zip
Gnt1.0TrainPart3.zip
Gnt1.1Test.zip
Gnt1.1TrainPart1.zip
Gnt1.1TrainPart2.zip
Gnt1.2Test.zip
Gnt1.2TrainPart1.zip
Gnt1.2TrainPart2.zip
```

`chinese_characters.txt` 是目标 7,185 个汉字清单，每行一个字符，准备源码包时也应包含它。`data/EMNIST/` 需要：

```text
emnist-byclass-mapping.txt
emnist-byclass-train-images-idx3-ubyte.gz
emnist-byclass-train-labels-idx1-ubyte.gz
emnist-byclass-test-images-idx3-ubyte.gz
emnist-byclass-test-labels-idx1-ubyte.gz
```

安装依赖后运行：

```bash
.venv/bin/python prepare_data.py
```

准备过程保留原始包，提取 GNT/IDX 并构造索引。过滤 135 条零尺寸记录和 1 张空白图；CASIA 中非目标符号不进入训练。EMNIST 图像在加载时转置一次，外部推理图片不应再次套用 IDX 转置。

CASIA 使用互不重叠的训练、验证、测试书写者，保留官方测试集；EMNIST 保留官方测试集，训练与验证按类别分层划分，但无法基于缺失的书写者 ID 证明书写者隔离。

## 上传时记录什么

推荐只发布完整处理目录，避免重复上传原始压缩备份。为每份发布文件提供稳定 URL、数据版本、字节大小及 SHA-256；分卷时注明完整分卷列表与合并方法。处理数据约 23 GiB，实际发布大小以打包文件为准。GitHub Release 的每个附件必须小于 2 GiB，可分卷或使用外部数据托管平台，限制见 [GitHub 官方说明](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)。

macOS 可使用 `shasum -a 256 文件名`，Windows PowerShell 可使用 `Get-FileHash 文件名 -Algorithm SHA256` 计算发布文件校验值。记录元信息中的类别数量、划分统计、准备参数与 `index_sha256`，并随包附上本说明。

获取和再分发遵循上游数据集条款，CASIA 使用要求见[协议页面](https://nlpr.ia.ac.cn/databases/handwriting/Application_form.html)。本项目源码仓库的发布不改变原始数据的授权条件。
