# 完整实验报告模板

本文用于完成实验后填充两份 README 末尾。未测量项目填写“未测量”，计划中的实验填写“未完成”，不得推算成实际成绩。现有阶段性成绩见[实验记录](实验记录.md)。

## 可复现信息

| 项目 | 填写内容 |
|---|---|
| 代码 | Git commit、是否有未提交修改 |
| 数据 | 发布版本、下载链接、发布文件 SHA-256、index SHA-256 |
| 数据协议 | 类别顺序、训练/验证/测试数量、书写者隔离限制 |
| 系统与依赖 | OS、Python、PyTorch、torchvision、CUDA、NVIDIA 驱动 |
| 硬件 | GPU 型号与显存、CPU、RAM、数据所在磁盘 |
| 训练 | 完整配置、随机种子、参数量、物理 batch、梯度累积、精度 |
| 实际预算 | 完成轮数、抽样次数、成功更新次数、总训练时间、是否提前停止 |
| 模型选择 | EMA 或原模型、验证指标、验证子集或全量、检查点路径 |
| 测试 | 固定方案后运行的独立测试划分、实际样本数、完整评估 JSON |

默认训练一轮是有放回的固定抽样预算，不等于全量训练集的一遍。若有多次随机种子实验，保留每次结果并报告均值与标准差；只有一次时明确注明。中断恢复未保存全部 RNG 状态，不保证逐位复现。

## 主要结果

使用完整独立测试集，报告 Top-1、Top-5、宏平均 Top-1。基线与本项目保持相同类别、数据划分和可比训练预算；标明参数量、是否预训练、输入分辨率、计算量差异。不同类别数量或文本行识别结果不能直接混入同一比较表。

分别报告汉字、数字、大写、小写的测试样本数、Top-1 和 Top-5。保留最易错字符及混淆对，特别检查 `O/0`、`l/I/1`、大小写相似写法与汉字近形字。低样本分组的变化需要结合样本数解释。

## 消融与预算

计划比较完整模型、关闭 Sobel、关闭空间注意力、取消多尺度融合、替换线性分类头。先实现对应变体再开展实验；当前不能把这些计划写成已完成支持。每次只改变被研究的因素，并记录参数量、预算与随机种子。

## 图像与运行效率

- 将学习曲线、混淆分析、预测样例放入 `docs/assets/`，然后同步启用两份 README 的图片位置。
- 训练曲线注明损失与验证指标、子集数量、最佳检查点及提前停止位置。
- 同时提供正确与错误示例，注明真值、预测、候选分数与输入来源，避免只展示成功案例。
- 将外部照片、纸笔输入等真实场景结果与官方测试集结果分开。
- 吞吐与延迟注明硬件、精度、batch、预热次数、设备同步、是否含预处理与读盘；吞吐不能直接取倒数当作单张端到端延迟。
- 记录实际峰值显存及测量方法。MPS 与 CUDA 的测量方式和内存口径可能不同。
